## Operation Rules

- 只能读写仓库目录内的文件。禁止读取剪贴板，禁止读取其他 Agent / IDE 的会话记录目录（brains、transcripts 等），禁止扫描仓库外的磁盘目录。找不到需要的文档时停下来问我，不要全盘搜索。

## Git Commit Rules

- Use the existing Git user.name and user.email.
- Never modify Git author or committer identity.
- Do not automatically add AI agents as commit co-authors.
- Do not add AI attribution trailers such as Co-authored-by
  or Made-with unless required by repository policy.
- Never execute git commit or git push without explicit
  user approval.
- Follow all repository AI disclosure requirements.
