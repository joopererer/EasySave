### 格式支持矩阵

| 格式 | XMP 读取 | XMP 写入 | C2PA 检测 | 备注 |
|---|---|---|---|---|

| GIF | - | - | - | sidecar 延后 |

### 已知限制

| 限制 | 原因 | 解决方式 |
|---|---|---|
| X 平台的 authorId 未写入 | 统一模型中 X 的 `author.id` 是用户名（如 `n8_AIart`），不是稳定的数字 ID | 元数据层对 X 不写 `authorId`；后续在解析器中提供数字用户 ID |
| `itemIndex` 从 1 开始 | 规范要求 1-based，与文件名序号一致 | 已修复 |
| 视频文件不写元数据 | MP4 `uuid` box 需要片段化 MP4 处理 | 延后；用户可在 HistoryDb 和 Windows 资源管理器中查看来源 |
| GIF/HEIC/AVIF/RAW 不写元数据 | 这些格式不支持嵌入式 XMP | 延后；sidecar 方式 |
| C2PA 签名文件跳过写入 | 嵌入 XMP 会使签名失效 | 未来：写入 sidecar |
| 作用域存储限制 | Android 11+ 行为 | `MediaStore.createWriteRequest` 批量请求写权限 |

### 对 SPEC 的修改建议

1. **X 平台 authorId**：建议在 SPEC 中明确说明 `prov:authorId` 的来源要求，或在平台特定字段中允许用户名作为 fallback</2>
