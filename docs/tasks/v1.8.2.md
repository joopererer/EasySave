## 开发环境说明

### Kotlin 单元测试运行方式
在 `app/android/` 目录下运行 Kotlin 单元测试：
1. 确保已设置 `JAVA_HOME` 环境变量指向 JDK 17（例如 Android Studio 自带的 JBR 目录：`set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr`）。
2. 执行测试命令：
   ```bash
   gradlew testDebugUnitTest
   ```
   或在项目根目录下执行：
   ```bash
   cd app/android && gradlew testDebugUnitTest
   ```

### 根目录 build.gradle.kts 为插件子项目禁用测试任务的原因
在 `app/android/build.gradle.kts` 中配置了：
```kotlin
subprojects {
    project.evaluationDependsOn(":app")
    if (project.path != ":app") {
        tasks.matching { it.name.contains("Test", ignoreCase = true) }.configureEach {
            enabled = false
        }
    }
}
```
**原因**：Flutter 在 Android 构建中会将所有引用的第三方原生插件（例如 `photo_manager`、`path_provider_android` 等）作为 Gradle 子项目自动挂载到根项目中。这些第三方插件大多未维护单元测试或未正确配置测试环境，在运行 Gradle 测试任务（如 `./gradlew test` 或带子项目扫描的测试）时会由于第三方插件本身的配置缺失导致构建报错中断。因此，在根构建脚本中显式过滤并禁用所有非 `:app` 子项目的测试任务，保证单元测试仅在主应用 `:app` 范围内稳定执行。
