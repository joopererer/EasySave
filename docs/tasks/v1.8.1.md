# v1.8.1 任务文档

## 目标
接入 `provenance_dart` 共享包，替代 `app/lib/metadata/` 中的重复实现，对齐 `provenance-spec` 规范。

## 后续任务
1. **补写非原子写校验与 ContentResolver "wt"**：
   调研并验证 Android 11+ 相册内覆盖写是否支持无临时文件的原子替换，或评估直接 `openOutputStream(uri, "wt")` 的可行性。当前补写路径使用 `File.writeAsBytes(newBytes, flush: true)` 避免在共享目录产生 `.tmp` 临时文件，但相册覆盖写非原子操作，需在后续版本评估系统 API 级支持。
2. **重建历史时缺失 sourceUrl 补填问题**：
   当前从相册重建历史时，若 XMP 缺失 `sourceUrl`，`HistoryRecord.postUrl` 补填了 `'https://unknown'`，规范应为 `null`。需统一评估历史记录数据库与 UI 展示对 `postUrl` 为空的处理后进行修正。
