- [x] 44. 删除语义：默认仅删记录 + SnackBar [撤销]（`reinsert` 恢复记录，不涉及文件）；勾选删文件时先调系统删除（不可撤销），成功则"文件与记录双删"，用户拒绝或系统不支持则"仅删记录"并提示"相册文件已保留"
- [x] 45. 仅 `FileStatus.found` 的文件计入"同时删除相册中的 M 个文件"并参与删除；`unknown`/`not_found` 既不计入也不尝试删除（`deletableMediaFor` 过滤）
- [x] 46. 原生 `MediaStore.createDeleteRequest`：新增 `easysave/media` 平台通道（`MainActivity.kt`）。Android 版本差异处理：
  - **API ≥ 30 (R)**：`MediaStore.createDeleteRequest` 将全部 URI 合并为一次系统确认，经 `ActivityResultContracts.StartIntentSenderForResult` 回传用户是否同意（无需存储权限）
  - **API 29 (Q)**：批量删除 API 不存在，MediaStore 仅提供按单文件的 `RecoverableSecurityException`（逐文件弹窗，无法通过单个 MethodChannel 结果优雅收敛），本实现返回 `false`，回退为仅删记录并提示相册文件已保留
  - **API < 29**：不再申请写外部存储权限，同样返回 `false` 走仅删记录回退
- [x] 47. 底部导航替换：多选激活时通过 `onSelectionModeChanged` 通知 `MainShell` 隐藏其 `BottomNavigationBar`，由历史页渲染自己的分享/删除操作栏
