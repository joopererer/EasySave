# v1.3b 任务清单：解析器云端热更新

- [x] 1. 密钥规范与说明：提供本机生成 Ed25519 密钥对的命令与 GitHub Secrets 配置说明；公钥作为常量内置于 App 中，私钥严禁入库
- [x] 2. Manifest 规范与打包签名脚本：定义 manifest.json 格式（parserVersion、minAppVersion、sha256、signature、platforms 平台开关及维护提示、headers/UA），编写打包与签名脚本
- [x] 3. GitHub Actions 发布工作流：创建 `.github/workflows/release_parser.yml`，推送 `parser-v*` tag 时运行全部测试、打包 parser.js、计算 sha256、签名并生成 manifest.json，发布到 GitHub Releases
- [x] 4. App 端验签与更新管理（UpdateService）：使用 cryptography 验签 Ed25519，crypto 校验 sha256，每 6 小时检查一次更新，缓存可用版本到本地存储；校验失败、下载失败、minAppVersion 不满足时回退到内置 assets/parser/parser.js
- [x] 5. App 端解析接入与远程开关：parse_service.dart 优先使用最新可用 parser.js；平台被远程关闭时显示维护提示且不发起任何请求
- [x] 6. App 端 UI 与诊断信息：在"我的"页和诊断信息中显示当前解析器版本及来源（内置 / 云端）
- [x] 7. 插件端 MV3 远程配置：只在 background.ts 中拉取 manifest.json 应用平台开关和请求头配置，解析模块保持纯函数，不加载执行远程代码
- [x] 8. 单元测试：为 Ed25519 验签、sha256 校验、minAppVersion 判定、回退逻辑及平台远程开关编写 Dart 单元测试
- [x] 9. 验收与提交：npm test、flutter analyze、flutter test、flutter build apk --release 全部通过后提交，汇报命令执行结果及真机测试验证流程
