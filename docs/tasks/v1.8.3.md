# v1.8.3 任务文档

## 目标
1. **悬浮球选择下载全屏大图/视频预览**：
   - 悬浮球选择下载面板（`SelectPanelView`）支持长按缩略图全屏/大屏预览；
   - 支持图片高清大图加载与视频全屏播放（视频默认静音循环播放）；
   - 设置页增加“大图预览常驻”选项（默认否：按住预览、松手即退；开启后长按弹窗常驻、点击关闭）；悬浮球关闭时该设置项联动置灰不可选。
2. **Instagram 敏感/年龄限制与无 SSR 直出帖子解析**：
   - 自动检测并同意敏感内容/年龄限制前置拦截屏（Auto-dismiss Interstitial）；
   - 在 Android Headless WebView 注入网络拦截机制（Fetch/XHR Sniffing），捕获异步 GraphQL 接口数据，解决无 SSR `data-sjs` 直出数据的帖子解析问题；
   - 优化受阻报错文案与用户引导。

## 关键实现说明

### 1. 悬浮球全屏预览与常驻设置
- **原生悬浮层扩展（`SelectPanelView.kt` & `HostService.kt`）**：
  - 在 `SelectPanelView` 顶层增加全屏预览遮罩层 `previewOverlay`（深色半透明背景，居中展示大图 `ImageView` 或全屏视频 `TextureView`，顶部标题/计数器与关闭按钮，中间显示居中进度圈）。
  - 视频播放采用轻量原生 `MediaPlayer` 绑定 `TextureView`，默认静音（`setVolume(0f, 0f)`）并循环播放（`isLooping = true`），自动复用 WebKit Cookie 与移动端 UA。
  - 支持两种交互模式：
    - **非受驻模式（默认）**：按住缩略图触发预览，手指松开（`ACTION_UP` / `ACTION_CANCEL`）即刻退回选择面板。
    - **常驻模式**：长按触发全屏预览后悬浮常驻，用户可从容查看，点击遮罩/关闭按钮退回。
- **配置与设置联动（`settings.dart`、`mine_page.dart`、`backup_service.dart`）**：
  - 新增 `bubblePreviewSticky` 配置（默认 `false`），纳入本地配置存储与备份/恢复体系；
  - 在我的页面快捷入口区域，增加“大图预览常驻”开关，并在悬浮球总开关关闭时联动置灰禁用（`onChanged: _settings.bubbleEnabled ? ... : null`）。

### 2. Instagram 敏感/年龄拦截屏与客户端 GraphQL 嗅探
- **网络嗅探桥接（`parse_service.dart`）**：
  - 在 `HeadlessInAppWebView` 容器启动时通过 `initialUserScripts` 在 `UserScriptInjectionTime.AT_DOCUMENT_START` 注入网络嗅探脚本；
  - 拦截所有通过 `window.fetch` 与 `XMLHttpRequest` 发往 Instagram GraphQL 接口（`api/v1/users/web_profile_info`、`/graphql/query`、`PolarisPostRootQuery` 等）的请求，自动解析出帖子结构并缓存在 `window.__easysaveIgProducts[shortcode]`。
- **敏感内容/年龄拦截屏自动同意**：
  - 针对年龄限制或敏感警告弹层，注入自动同意逻辑，自动点击 "See post" / "查看帖子" / "了解详情" 等按钮触发客户端 GraphQL 请求。
- **多重降级解析机制（`instagram.ts` & `_parse_page.ts`）**：
  - 依次尝试：SSR 直出 `data-sjs` 解析 -> 网络嗅探捕获的数据 `window.__easysaveIgProducts[shortcode]` -> 降级错误提示；
  - 针对敏感内容和年龄拦截，给出准确友好的提示说明，避免误报为“登录受限外壳”。
