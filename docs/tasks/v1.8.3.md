# v1.8.3 任务文档

## 目标
1. **悬浮球选择下载全屏大图/视频预览**：
   - 悬浮球选择下载面板（`SelectPanelView`）支持长按缩略图全屏/大屏预览；
   - 支持图片高清大图加载与视频全屏播放（视频默认静音循环播放）；
   - 设置页增加“大图预览常驻”选项（默认否：按住预览、松手即退；开启后长按弹窗常驻、点击关闭）；悬浮球关闭时该设置项联动置灰不可选。
2. **Instagram 敏感/年龄限制与无 SSR 直出帖子解析**：
   - 自动检测并同意敏感内容/年龄限制前置拦截屏（Auto-dismiss Interstitial）；
   - 在 Android Headless WebView 注入网络拦截机制（Fetch/XHR Sniffing），捕获异步 GraphQL 接口数据，解决无 SSR `data-sjs` 直出数据的帖子解析问题；
   - 优化受阻报错文案与用户引导。

## 关键实现说明

### 1. 悬浮球全屏预览与常驻设置
- **原生悬浮层扩展（`SelectPanelView.kt` & `HostService.kt`）**：
  - 在 `SelectPanelView` 顶层增加全屏预览遮罩层 `previewOverlay`（深色半透明背景，居中展示大图 `ImageView` 或全屏视频 `TextureView`，顶部标题/计数器与关闭按钮，中间显示居中进度圈）。
  - 视频播放采用轻量原生 `MediaPlayer` 绑定 `TextureView`，循环播放，自动复用 WebKit Cookie 与移动端 UA。
  - **常驻模式松手消失修复**：
    - 在常驻模式下，按住后触发长按弹窗时，长按结束手指抬起产生的 `ACTION_UP` / 点击穿透不会误关弹窗（设置 400ms 打开保护防抖缓冲，且松手事件不触发 `hidePreview`）。
  - **轮播滑动切换与左右切换按钮**：
    - 支持左右轻扫（Horizontal Fling）手势切换多图/视频。
    - 屏幕左右两侧增加轻量浮动切换指示按钮（`ChevronView`），通过 Canvas 矢量路径在圆形背景正中心精准绘制箭头，彻底解决不同字体下标点字符不对齐的问题。
  - **视频播放控制栏**：
    - 视频预览底部增加浮动控制栏：包含播放/暂停切换按钮（`PlayPauseView`）、进度条（`SeekBar`）、播放时间与总时长（`00:00 / 00:00`）。
    - 播放与暂停图标采用统一纯白色 Canvas 矢量绘制，消除了系统 Emoji 字符产生的颜色与尺寸不一致问题。
    - 支持拖动进度条精确定位播放进度（`mediaPlayer?.seekTo`），并由 250ms 定时器同步更新播放进度。
  - **常驻与非常驻模式精细化区分**：
    - 非常驻模式（默认）：按住缩略图触发预览，手指一旦离开屏幕（`dispatchTouchEvent` 捕获 `ACTION_UP`/`ACTION_CANCEL`）立刻关闭预览；隐藏右上角关闭按钮与左右切换按钮。
    - 常驻模式：弹窗常驻显示，显示右上角关闭按钮与切换指示按钮，支持点击遮罩、点击关闭按钮或按物理返回键退出。
  - **硬件物理返回键支持**：
    - 窗口参数移除 `FLAG_NOT_FOCUSABLE` 并开启焦点拦截（`dispatchKeyEvent`）；
    - 用户按下物理/手势返回键时，若处于大图预览状态，优先退出大图预览回到选择面板；再次按下返回键，关闭选择面板弹框。
- **配置与设置联动（`settings.dart`、`mine_page.dart`、`backup_service.dart`）**：
  - 新增 `bubblePreviewSticky` 配置（默认 `false`），纳入本地配置存储与备份/恢复体系；
  - `AppSettings.load()` 增加 `await prefs.reload()`，保证后台引擎即时获取主进程对常驻设置的最新修改；
  - 在我的页面快捷入口区域，增加“大图预览常驻”开关，并在悬浮球总开关关闭时联动置灰禁用（`onChanged: _settings.bubbleEnabled ? ... : null`）。

### 2. Instagram 敏感/年龄拦截屏与客户端 GraphQL 嗅探与 DOM 提取
- **参考开源/市面下载器（如 InSaver / Media Saver / yt-dlp）架构对齐**：
  - **标准 Mobile Chrome UA 伪装**：内嵌 Android WebView 默认带有 `Version/4.0` 与 `; wv` 标记，会被 Instagram 识别为受限 WebKit 壳并拦截媒体数据。在 `auth.dart` 与 `parse_service.dart` 中为 Instagram 配置无 WebView 标记的标准移动 Chrome UA。
  - **GraphQL 与网络嗅探增强**：拦截嗅探脚本与解析器全面兼容现代 Instagram GraphQL 结构（`xdt_shortcode_media`、`display_url`、`video_url`、`edge_sidecar_to_children`、`edge_media_to_caption`、`code`、`shortcode`）。
  - **DOM 提取器降级（`parseInstagramFromDom`）**：当 SSR 与网络嗅探因页面已加载未捕获时，直接提取真实渲染的 `<article video>`、`<article img>` 高清资源及 OpenGraph 标签（模拟市面下载器从渲染 DOM 获取资源的方式）。
  - **登录态假失效保护**：当用户在 App 内已完成登录（存在有效 session cookie）但特定帖子因受限或缺失直出数据返回空外壳时，在 `_reclassifyFailure` 中将其归类为受限或私密内容，避免误报“登录已失效，请重新登录”导致用户陷入重复登录死循环。
