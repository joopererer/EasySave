- [ ] After v1.10 phase 2c defines backup v2 file-row semantics, add multi-select deletion in post details.
- [ ] The confirmation must say that the selected files will also be deleted from the album. If every remaining file in the post is selected, instead explain that the post record will also be deleted.
- [ ] Delete a Live photo's image and video together as one selection.
- [ ] Keep the original post's `itemIndex` and `itemCount` metadata unchanged on all remaining files.
- [ ] Reuse the existing post deletion path, including MediaStore authorization, background cleanup, timeouts, and the download write barrier; do not introduce a parallel deletion implementation.

## Candidate: cookie-protected overlay video preview

- [ ] Evaluate a Dart-owned loopback stream for a single currently selected video, using a random port and one-time random path. Cookies remain in Dart; the native player receives only the local stream.
- [ ] Bind exclusively to loopback, use a single-use token with a short timeout, close the server when preview ends, and keep cookies and URLs out of logs. Review redirect authorization, cancellation, range requests, and concurrent previews before implementation.
